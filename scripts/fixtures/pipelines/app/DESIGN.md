# Design context

## Visual character

Calm and plain: one column, generous space, one accent colour.

## Typography and hierarchy

System font. One heading, body text, a muted note for secondary details.

## Density and layout

A single 32rem column with an 8px spacing scale (16, 24, 48).

## We do

- Keep all text at AA contrast or better, including muted text.

## We do not

- Use light grey text on white.
